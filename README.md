# banana clicker 🍌

Mutation Fruit is a dark-humor idle clicker game made with **Python (Tkinter)**.

Click to earn fruit, buy generators for passive income, unlock weird banana types, and prestige to gain **Mutation Points** that boost your clicks and income.

## Features
- 🍌 Clicker + idle income system
- 🏭 Generators (farms, plantations, quantum stuff...)
- 🧬 Prestige / Mutation Points system
- 🎲 Random events (bonus, thief, market pump, etc.)
- 💾 Save / Load system (JSON)
- 💀 Roast dialog system that insults you while you grind

## How to Run
1. Install Python 3.x  
2. Run the game:

```bash
python main.py
Controls
Click the 🍌 CLICK button to earn fruit
Buy generators for passive income
Upgrade click power
Prestige to reset and gain Mutation Points
